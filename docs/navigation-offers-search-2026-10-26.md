# Navigation, notifications, offers and community search

- One shared five-position navigation: Today, Unmask, a larger Create action, Product and You. The centre action opens the existing Share / Ask / Track menu. The floating action button is removed. Older utility pages use the same component.
- Notifications use compact tappable rows, unread dots, relative times and date groups. Opening a row acknowledges it. Mark-all-read and settings are accessible icon actions. Demo updates remain labelled. Legacy thread acknowledgements are stored locally per account because the legacy API only supports marking the entire collection read; the explicit mark-all action still syncs that collection.
- Home has a horizontal offer showcase. Offer cards show the seller, product, supplied price, genuine supplied price reduction, disclosure and an experience-count action. Unknown counts are not shown as zero. Zero experiences lead to a community question. Live prices are optional; sample prices are fictional. Admin offer editing now includes optional current/previous price and currency fields.
- Comment sheets always offer Join conversation, including demo previews and signed-out views. Live sheets retain the signed-in composer. Ultra Unmask detail pages now expose their conversation action too.
- Main text search now queries the community catalogue directly, without the old research endpoint or Serper. Selected products are checked for public experiences, questions or Ultra Unmasks. Existing conversations open the product page; empty products lead to the question form. Unknown products can start a question using their supplied name. Query errors stay errors rather than being described as no evidence. This search covers catalogue product/brand names, not an external global catalogue. The existing photo identification entry remains available.

Validation: TypeScript, Expo web export, 112 tests including price math and search-filter handling. Additive price-column migration applied and column presence verified. No user records, existing offers or experience data were deleted.
